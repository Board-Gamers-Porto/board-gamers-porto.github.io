# Boardgamers Porto

Website built with Astro. Requires Node.js **22.12.0 or newer** and npm.

Run the commands below from this directory (`website/`).

## Install dependencies

```sh
npm ci
```

## Local development

```sh
npm run dev
```

Open the local URL printed in the terminal. The development server reloads as you edit files. Press `Ctrl+C` to stop it.

## Production build

```sh
npm run build
```

The generated site is written to `public/`.

To preview the production build locally:

```sh
npm run preview
```

Open the URL printed in the terminal. Run `npm run build` again after making changes to refresh the preview.
